Secure-SSH-Server

The house floor plan crossed with a delivery register. Ride the car upward through what ssh.sh actually does on an Arch Linux machine, one panel per floor.

Open the repo The return trip

G

Ground floor: before anything leaves the kitchen

chmod +x ssh.sh
./ssh.sh

The script asks two questions: a port, with 25 offered as the default if you just press enter, and a username.

The port must be a whole number from 1 to 65535.

The username must begin with a lowercase letter or underscore, use only lowercase letters, digits, hyphens, and underscores, and run to at most 32 characters.

A name that already belongs to an account on the machine is refused outright.

Invalid answers stop the script with an error. Nothing has been changed yet at this point.

K

Kitchen: loading the car

The script installs openssh with pacman if it is missing.

It creates the user with a home directory.

It sets a password it generated itself from openssl rand -base64 12.

That password is stored in no file. The printed connection details at the end are its only copy.

1

First floor: locking the doors behind the cargo

The existing /etc/ssh/sshd_config is copied to /etc/ssh/sshd_config.bak, and a hardened replacement is written.

Note tied to the rope: a backup left by an earlier run is kept rather than overwritten.

Root login refused. Password login allowed for the new user. Empty passwords refused.

Agent forwarding off. TCP forwarding off. Tunnelling off. X11 forwarding off.

MaxAuthTries 3. MaxSessions 3. Login grace time 30 seconds.

Permitted ciphers: chacha20-poly1305@openssh.com, aes256-gcm@openssh.com, aes128-gcm@openssh.com.

Permitted MACs: hmac-sha2-256-etm@openssh.com, hmac-sha2-512-etm@openssh.com, umac-128-etm@openssh.com.

The new file is tested with sshd -t before any restart. If it fails, the backup goes straight back and the script stops.

2

Top floor: arrival

sshd is restarted and enabled.

The script prints where to connect: the machine's IP addresses with loopback left out, the chosen port, the username, and the generated password.

Any SSH client can make the connection. The README names Termius and Prompt 2.

B

Back stairs: the return trip

The server lives only while the script runs. Ctrl+C or SIGTERM triggers a cleanup that ends the user's sessions, deletes the user and its home directory, stops sshd and disables it so a reboot cannot revive the server, and restores the backed up sshd_config.

Cleanup deletes the user the script created, so do not point the unedited script at an account worth keeping.

Requirements: Arch Linux, sudo, openssl, and the ip command from iproute2.

Verification for the script is bash -n plus the static checks in test_ssh_static.py run under python3 -m unittest, since the script itself needs an Arch machine with sudo to run for real.
